# Notebook 文件含义

## 1. 前缀含义

1. benchmark_*: 用于进行基准测试的notebook。
2. dev_*: 方法开发过程中用到的notebook。
3. quickstart_*: 单个方法快速执行的notebook。

## 2. 数据

1. 模拟数据
   - cellrank_simulation: cellrank Fig1中的模拟数据。
   - dyntoy_bifuracting_1: dynverse benchmark中的模拟分支数据。
2. 真实数据
   - scvelo_pancreas：scvelo tutorial中胰腺数据。
   - real_silver_fibroblast-reprogramming_treutlein：dynverse benchmark中的成纤维细胞重编程数据。
