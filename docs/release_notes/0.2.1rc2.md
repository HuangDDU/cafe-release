## 0.2.1rc2 <span class="cafe-release-date">2026-10-13</span>

**Added**

- One-call downstream analysis with `cafe.downstream.driver_genes`.
- `DriverGeneResult.top_genes` for per-lineage DE candidate ranking, significance, and direction filtering.
- CLI and object-level launch helpers for native CELLxGENE and `cafe-cellxgene`.
- Download actions for all rendered tutorial notebooks.
- Reorganized introduction documentation for the user guide.
- Metacell trajectory inference experiments.
- `get_milestone_order` support for `MilestoneWrapper`.
- Development documentation updates for contribution workflows.
- Local-only documentation test area under `docs/test`.
- Release notes and references documentation infrastructure.
- GitHub Actions workflows for package checks, TestPyPI publishing, and PyPI publishing.
- Release workflow documentation for PEP 440 release candidates.

**Changed**

- Grouped driver-gene internals under `downstream/_driver_genes` while keeping generic lineage extraction separate.
- Simplified method selection to an explicit class map; the function entry validates inputs before computing on a single method instance.
- Delegated lineage model lookup to `FateAnnData` instead of parsing model names again.
- Limited the public downstream export to `driver_genes` and removed the intermediate `DriverGene` manager.
- Extracted velocity wrapper logic for cleaner method integration.
- Updated future-work planning for Cafe v2.
- Optimized project configuration details.
- Temporarily excluded method-function integration tests from default pytest and VS Code test discovery.
- Updated the package version to the `0.2.1rc2` release candidate.

**Fixed**

- Excluded named DE reference lineages from target comparisons, with explicit reference and test validation.
- Fixed the `cellxgene-cafe` plugin launch function.
- Preserved dictionary-backed waypoint data when preparing `FateAnnData` for serialization.
- Corrected the `cellxgene-cafe` tutorial index link.

**Maintenance**

- Added cleanup of generated `.cafe` test artifacts.
- Added launcher and CLI regression tests.
- Included the Jupyter runtime dependency in package metadata.
