## 0.2.1 <span class="cafe-release-date">2026-10-14</span>

**Added**

- Added one-call driver-gene analysis with lineage-aware ranking and filtering.
- Added native CELLxGENE and `cafe-cellxgene` launch helpers.
- Added download actions for rendered tutorial notebooks.
- Added automatic first-use download for `cafe.data.read_pancreas()`.
- Added release notes, contribution documentation, and automated TestPyPI/PyPI publishing infrastructure.

**Changed**

- Reorganized driver-gene, method-selection, and velocity-wrapper internals while preserving the public workflow.
- Reorganized the introduction documentation and updated the quickstart dataset instructions.
- Changed the default dataset directory from a developer-specific absolute path to the local `data` directory.
- Promoted the validated `0.2.1rc3` release candidate to the stable `0.2.1` release.

**Fixed**

- Fixed lineage-reference handling in differential-expression comparisons.
- Fixed CELLxGENE plugin launching and tutorial navigation.
- Preserved dictionary-backed waypoint data during `FateAnnData` serialization.
- Restored development notebooks that were unnecessarily removed during release preparation.

**Maintenance**

- Added regression coverage for launchers, CLI behavior, Pancreas download configuration, and the default data directory.
- Added cleanup rules for generated test artifacts.
