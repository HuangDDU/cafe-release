## 0.1.0 <span class="cafe-release-date">2024-12-24</span>

**Added**

- Initial Cafe project framework.
- Core source package with data, method, plot, utility, logging, and settings modules.
- `FateAnnData`, `MilestoneWrapper`, and `WaypointWrapper` foundations.
- Method backend abstraction with function, Cafe Docker, and Dynverse Docker backends.
- Initial MkDocs documentation, quickstart notebooks, and unit test structure.
- Early PAGA Docker integration and method execution workflow.

**Changed**

- Established the initial development workflow:
  - create feature branches from `dev`;
  - write source code and tests locally;
  - update documentation;
  - merge through `dev` and `main`;
  - tag releases after GitHub Actions and ReadTheDocs checks.
