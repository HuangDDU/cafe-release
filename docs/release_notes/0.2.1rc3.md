## 0.2.1rc3 <span class="cafe-release-date">2026-10-14</span>

**Added**

- Added automatic first-use download for `cafe.data.read_pancreas()` through Scanpy's `backup_url` support.
- Added regression tests for the default data directory and Pancreas download configuration.

**Changed**

- Changed the default dataset directory from a developer-specific absolute path to the local `data` directory.
- Updated the quickstart tutorial to explain automatic dataset download and optional custom data directories.

**Fixed**

- Restored development notebooks that were unnecessarily removed from the `main` branch during the previous release.

**Maintenance**

- Updated the package version to the `0.2.1rc3` release candidate.
