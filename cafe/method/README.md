1. fate_backend.py: Base class for 4 backends.
2. fate_function_backend: Function backend.
3. fate_conda_backend.py: Conda backend.
4. fate_cafe_docker_backend.py: Cafe docker backend.
5. fate_dynverse_docker_backend.py: Dynverse docker backend.
6. fate_method: Method class which will call 4 backends.
7. Dockerfile: Dockerfile for cafe docker backend.
8. environment: Conda environment yaml files for cafe conda backend.
9. function: Trajectory inference core function.
10. method_util: Scan methods.
